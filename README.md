# Threads Lite

Учебный проект в рамках лабораторной работы по "Современным технологиям разработки ПО".
Это упрощенная вариация соц сети для распространения текстовых публикации на основе фреймворка FastApi
на Python:
- публикация коротких текстовых постов с тегами и комментариями
- возможность оставлять лайки, сохранять избранное
- а также две роли — пользователь и админ.

**Стек:** FastAPI · SQLAlchemy 2 · Alembic · SQLite (это временно, честно честно xD) · JWT · Argon2.

## Инструкция по Запуску

Ну сначала как обычно клонируете репозиторий из гитхаба, а дальше по списку...
Все команды выполняются из корня проекта.

```powershell
# 1. Активировать виртуальное окружение и поставить зависимости
.venv\Scripts\activate
pip install -r requirements.txt

# 2. Создать файл настроек (если его ещё нет) и вписать свой SECRET_KEY
copy .env.example .env

# 3. Создать таблицы в базе (применить миграции)
alembic upgrade head

# 4. Создать администратора
python -m app.create_admin admin

# 5. Запустить сервер
uvicorn app.main:app --reload
```

Откройте <http://127.0.0.1:8000/docs> — это Swagger UI. Там можно вызывать все методы прямо из браузера,
иначе говоря глянуть как что робит.
Чтобы действовать от имени пользователя, нажмите **Authorize** и введите логин и пароль.

## Структура проекта

```
app/
  main.py          — создание приложения, подключение роутеров
  config.py        — настройки из .env
  database.py      — подключение к БД, сессии
  models.py        — таблицы (ORM-модели)
  schemas.py       — что API принимает и отдаёт (Pydantic) + валидация
  security.py      — хеширование паролей, JWT
  dependencies.py  — текущий пользователь, сессия БД (Depends)
  services.py      — общая логика: права доступа, теги, сборка ответа поста
  create_admin.py  — консольная команда создания админа
  routers/
    auth.py        — регистрация, вход
    users.py       — профиль, избранное
    posts.py       — посты, лайки, избранное, комментарии к посту
    comments.py    — изменение/удаление комментария
    tags.py        — список тегов
alembic/           — миграции базы данных
```

## API

| Метод | Путь | Кто может | Описание |
|---|---|---|---|
| POST | `/auth/register` | все | регистрация (JSON: `username`, `password`) |
| POST | `/auth/login` | все | вход (form-data), возвращает JWT |
| GET | `/users/me` | авторизованный | свой профиль |
| GET | `/users/me/favorites` | авторизованный | избранные посты |
| GET | `/users/{username}` | все | профиль пользователя |
| GET | `/posts` | все | лента: `limit`, `offset`, `tag`, `author`, `search` |
| POST | `/posts` | авторизованный | создать пост (`text`, `tags`) |
| GET | `/posts/{id}` | все | один пост |
| PATCH | `/posts/{id}` | автор | изменить текст и/или теги |
| DELETE | `/posts/{id}` | автор или админ | удалить пост |
| POST / DELETE | `/posts/{id}/like` | авторизованный | поставить / снять лайк |
| POST / DELETE | `/posts/{id}/favorite` | авторизованный | добавить / убрать из избранного |
| GET | `/posts/{id}/comments` | все | комментарии к посту |
| POST | `/posts/{id}/comments` | авторизованный | написать комментарий |
| PATCH | `/comments/{id}` | автор | изменить комментарий |
| DELETE | `/comments/{id}` | автор или админ | удалить комментарий |
| GET | `/tags` | все | популярные теги с числом постов |

Тут парочка правил для удобства:
- пост — до 1000 символов, комментарий — до 500, тегов у поста — не больше 10;
- теги приводятся к нижнему регистру, `#` в начале отбрасывается: `#Python` → `python`;
- лайк и избранное идемпотентны: повторный запрос не вызывает ошибку;
- админ может удалять любые посты и комментарии, но редактировать чужие не может;
- при удалении поста автоматически удаляются его комментарии, лайки и записи в избранном.

## Миграции — нужны чтобы хранить историю версий наших моделей

Если вы изменили модели в `models.py`, создайте и примените миграцию:

```powershell
alembic revision --autogenerate -m "что изменилось"
alembic upgrade head
```

## Переход на PostgreSQL

в будущем поменяю, чтобы из под коробки было сразу как надо, но а пока что
всё робит на обычном SQLite и при желании можно перейти на PostgreSQL следующими командами:

1. `pip install "psycopg[binary]"`
2. Создать базу в Postgres и поменять в `.env`:
   `DATABASE_URL=postgresql+psycopg://user:password@localhost:5432/threads`
3. `alembic upgrade head`

Код приложения менять для этого не нужно.
